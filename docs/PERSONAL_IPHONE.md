# Personal iPhone version

This fork uses openGym with VITE_LOCAL_ONLY=1: an empty workout history, browser storage, no server or login, and no simulated AI coach. Original licences and credits remain in place.

## Free deployment

Enable GitHub Actions in the fork, then Settings → Pages → Source → GitHub Actions. Run “Deploy personal workout app” from Actions. GitHub Pages serves the public app; workout data stays in the device browser. No paid server or custom domain is required.

## iPhone

Open the published URL in Safari → Share → Add to Home Screen. Use the home-screen app consistently. Test saving a workout and reopening it before relying on it.

## Backups

Settings → Data & backup → export a backup, saving it to Files. Use the ZIP export when you add custom photos or videos. There is no automatic cross-device sync. Clearing website data, removing the app, or browser storage eviction can lose local data. Keep backups outside the browser.
